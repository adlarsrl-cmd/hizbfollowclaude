# 🚀 HizbFollow - Deployment Checklist

## ✅ Pre-Deployment

### 1. Environment Variables
- [ ] Set `VITE_SUPABASE_URL` in production environment
- [ ] Set `VITE_SUPABASE_ANON_KEY` in production environment
- [ ] Remove or protect any `.env` files from git
- [ ] Verify environment variables are loaded correctly

### 2. Database Setup
- [ ] Apply all migrations in Supabase SQL Editor (especially `20251105000000_add_missing_indexes.sql`)
- [ ] Verify RLS policies are enabled on all tables
- [ ] Test database queries with different user roles
- [ ] Set up database backups (automatic in Supabase)

### 3. Authentication & Security
- [ ] Configure Supabase Auth settings:
  - [ ] Enable/disable email confirmation based on needs
  - [ ] Set up password requirements (min 8 characters recommended)
  - [ ] Configure session timeout
  - [ ] Set up CAPTCHA for signup (optional but recommended for public deployment)
- [ ] Review and test RLS policies for each role (owner, manager, member, viewer)
- [ ] Ensure members can only see their own data

### 4. Build & Testing
- [ ] Run `npm run build` and verify no errors
- [ ] Test the production build locally with `npm run preview`
- [ ] Test all features with different roles:
  - [ ] Owner: Full access
  - [ ] Manager: Can manage participants
  - [ ] Member: Can only see own data + anonymous stats
  - [ ] Viewer: Read-only access
- [ ] Test offline mode and sync queue
- [ ] Verify PWA manifest and icons are correct

### 5. Performance
- [ ] Database indexes are applied (run the new migration)
- [ ] Images are optimized (icons should be <100KB each)
- [ ] Bundle size is reasonable (check with `npm run build`)

## 🔒 Security Hardening

### Critical
1. **RLS Policies**: Already enabled ✅
2. **Environment Variables**: Never commit `.env` files
3. **Password Requirements**: Enforced by Supabase (default min 6 chars)
4. **HTTPS**: Automatic with Netlify/Vercel
5. **Member Privacy**: Fixed ✅ - Members can't see other participants

### Recommended
1. **Rate Limiting**: 
   - Supabase has built-in rate limiting
   - Consider adding client-side debouncing for frequently called endpoints
   
2. **CORS Configuration**: 
   - Set allowed origins in Supabase dashboard
   - Add your production domain

3. **Email Verification**:
   - Currently disabled for easy signup
   - Enable in Supabase Auth settings for production

4. **Content Security Policy (CSP)**:
   - Add CSP headers via Netlify/Vercel config
   - Example: `netlify.toml`

5. **Monitoring**:
   - Set up error tracking (Sentry recommended)
   - Monitor Supabase logs regularly

## 🆘 Troubleshooting

### Common Issues

**"Missing Supabase environment variables"**
- Check `.env` file exists (local)
- Check environment variables set in deployment platform

**"No active group" error**
- User needs to create or join a group first
- Redirect to `/groups` page works automatically

**Member sees other participants**
- Clear browser cache
- Verify latest code is deployed
- Check RLS policies in Supabase

**Offline sync not working**
- Check service worker is registered
- Verify sync queue in browser DevTools > Application > Storage
